# 数据安全与合规说明

本仓库只包含原型代码、文档和合成数据。真实医疗数据接入前，应至少满足以下要求。

## 不提交到 GitHub 的内容

- 姓名、身份证号、手机号、详细地址、医保号、就诊卡号原文。
- 原始 HIS/LIS/PACS/EMR 导出文件。
- 可回溯到个人的患者级明细。
- 未经授权的检查报告、影像、病历文本。
- 含有真实患者信息的训练集、验证集、测试集、模型解释样本。

## 推荐处理

- 在院内或授权环境完成去标识化和主索引生成。
- 使用研究编号或不可逆哈希作为 `patient_id`。
- 将字段映射、单位换算、异常值规则和剔除规则写入审计日志。
- 模型训练、验证和 SHAP 解释使用受控环境。
- 对导出的汇总报告进行小样本重识别风险检查。
- GitHub 仓库建议设为 private，并限制协作者范围。

## 研发分层

- GitHub：代码、合成数据、变量字典、流程文档。
- 受控计算环境：脱敏研究库、模型训练、校准、解释和验证。
- 医院信息系统：真实身份、诊疗流程、随访和转诊反馈。
