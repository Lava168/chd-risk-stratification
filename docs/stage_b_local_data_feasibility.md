# Stage B 本地真实世界数据可行性评估

Stage B 的目标是评估罗店/本地真实世界数据是否足以进入回顾性建模，而不是训练或发布临床可用模型。本阶段只提交脚本、字段模板和聚合统计，不提交患者级原始数据、原始 Excel、原始病历文本或个体预测结果。

## 当前不能直接训练的原因

- 当前表是就诊/报告级长表，不是一人一行宽表。
- 缺少结构化 `sbp`、`dbp`、`total_chol`、`ldl_c`、`hdl_c`、`fasting_glucose`、`smoker` 等核心预测变量。
- 缺少明确的 `outcome_chd`、`outcome_date`、`followup_end_date`。
- 缺少同来源非冠心病对照或普通社区/慢病管理人群。
- 如果文件主要来自冠心病相关业务库，只能支持病例描述或冠心病患者内部分层，不能支持普通居民发病风险预测。

## 建议分阶段命名

- Stage A：UCI 公开数据验证。证明训练、评估、图表和报告流程可复现，不代表罗店医院真实世界模型。
- Stage B：本地真实世界数据可行性评估。证明字段、时间范围、结局、缺失和对照人群是否具备。
- Stage C：本地回顾性训练与时间外验证。使用去标识化研究宽表训练并比较 China-PAR、Logistic/Cox、RF/XGBoost/LightGBM。
- Stage D：试点部署与闭环管理评估。接入随访、预警、转诊反馈和模型监测。
