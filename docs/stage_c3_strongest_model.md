# Stage C3：最强模型报告（基于本地 246 例）

> 目标：在现有数据下构造**可部署的最强模型**，并用严格方法（防泄漏、超参调优、10×5 重复分层 CV、时间外验证）诚实评估。

## 1. 方法

- **防泄漏**：`n_visits`、`hosp_count`、`ever_hospitalized` 一律不作为特征（防止用就诊次数预测住院）。
- **特征（22 个）**：年龄、性别、收缩压、脉压、总胆固醇 / LDL-C / HDL-C偏低 / 甘油三酯、血糖 / 空腹血糖 / 糖化、肌酐 / 尿酸 / 尿素氮、`has_lipids/has_glucose/has_renal/has_any_lab`（检验缺失指示）、吸烟、糖尿病、高血压、心电图异常。
- **调参**：每个模型在完整数据上用 5 折 GridSearchCV 选超参（Logistic C；RF 深度/叶节点；XGB/LGBM 深度/学习率/L2）。
- **评估**：10 次重复 5 折分层 CV（均值 + 95% CI）+ 时间外验证（index_date 前 209 / 后 37）。统一使用「插补+标准化」预处理器，保证结果即部署效果。
- **集成**：XGB + LGBM + RF 软投票（仅作研究对照）。

## 2. 结果（结局：是否住院，154/246 = 62.6%）

| 模型 | CV AUC | 95% CI | Brier | 时间外 AUC |
|---|---|---|---|---|
| logistic_regression | 0.859 | 0.753-0.963 | 0.153 | 0.7471 |
| random_forest | 0.868 | 0.755-0.957 | 0.153 | 0.8529 |
| xgboost | 0.871 | 0.780-0.960 | 0.143 | 0.8353 |
| lightgbm | 0.862 | 0.768-0.962 | 0.148 | 0.8426 |
| 集成(XGB+LGBM+RF) | 0.871 | 0.771-0.959 | 0.146 | - |

**最终部署模型：XGBoost**（CV AUC 0.871，时间外 AUC 0.835）→ `models/trained_model_bundle.joblib`

## 3. 分层验证（分数分位数 0.286 / 0.592 / 0.864）

| 档位 | 人数 | 平均预测概率 | 实际住院率 |
|---|---|---|---|
| 低危 | 88 | 0.149 | **18.2%** |
| 中危 | 69 | 0.439 | **73.9%** |
| 高危 | 89 | 0.670 | **97.8%** |

> 分层与真实结局高度单调一致，说明模型对「谁更可能住院」的排序是可靠的。
> 说明：本数据下几乎没有患者达到「极高危」切点（>0.864），因此该档为空；切点由训练分数分位数决定。

## 4. 为什么这已经接近「能用的上限」

1. n=246 且结局为 63% 高发——模型分数整体偏高，绝对风险阈值不适用，只能做**相对风险带**。
2. 时间外验证（0.835）与 CV（0.871）接近，说明过拟合可控，但 95% CI 仍宽（0.78-0.96）。
3. 进一步提升只能靠：更多样本、非 CHD 对照、人工复核的标签、结构化 LIS。
