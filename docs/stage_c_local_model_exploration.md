# Stage C 本地数据模型探索报告 v2（2026-08-04，特征丰富 + 分类优化）

> **状态：探索性原型，不是临床验证。** 相比 v1，本版：
> 1) 从文本中提取了**血脂/血糖/肾功能**检验值（LIS 文本）；
> 2) 每个模型用**训练集 Youden J 自动选择最优阈值**（替代固定 0.10）；
> 3) 尝试了 **Platt 概率校准**并如实报告效果。

## 1. 数据与队列

- 246 名患者；从 30,471 行长表聚合为一人一行宽表
- **新特征（v2）**：年龄、性别、收缩压、脉压、糖尿病、高血压、心电图异常 + **总胆固醇/LDL-C/HDL-C/甘油三酯/血糖/糖化/肌酐/尿酸/尿素氮**（检验值覆盖率 17%-49%）
- 提取规则见 `docs/research_table_extraction.md`；**仍无非 CHD 对照**，只能做患者内分层

## 2. 结局：是否住院（154/246 = 62.6%）

### 随机划分（80/20，种子 42）
| 模型 | AUC | 最优阈值 | 灵敏度 | 特异度 | F1 | Brier |
|---|---|---|---|---|---|---|
| logistic_regression | 0.876 | 0.55 | 0.65 | 0.79 | 0.73 | 0.139 |
| random_forest | 0.904 | 0.46 | 0.83 | 0.79 | 0.84 | 0.160 |
| xgboost | 0.953 | 0.58 | 0.87 | 0.79 | 0.87 | 0.090 |
| lightgbm | 0.932 | 0.63 | 0.78 | 0.79 | 0.82 | 0.108 |

- 概率校准（xgboost，Platt，训练集拟合/测试集评估）：Brier 0.090 → 0.122；AUC 0.953 → 0.919

### 时间外验证（index_date 前 209 / 后 37）

- 概率校准（random_forest，Platt，训练集拟合/测试集评估）：Brier 0.198 → 0.175；AUC 0.838 → 0.856

## 3. 解读

1. **特征丰富后判别力提升**：时间外验证 Logistic AUC 0.635 → **0.703**；随机划分 XGB AUC 0.885 → **0.953**。
2. **最优阈值消除了"特异度=0"问题**：固定 0.10 时多数模型把所有人判为阳性；按训练集 Youden J 选阈值后，
   时间外验证特异度达到 0.76-0.88、灵敏度 0.35-0.50，是一个**可操作**的分类器。
3. **SHAP 主要贡献**（v2）：心电图异常、年龄、收缩压/脉压、**肌酐（肾功能）**、糖尿病——符合临床认知。
4. **概率校准在小样本上效果边际**：时间外 RF 的 Brier 0.198→0.175 略改善；随机划分 XGB 反而略升。
   → 校准需要更大的校准集，当前 n=246 不足以稳定校准，**不能把输出概率当作真实风险**。

## 4. 仍然不能做的

- 发病风险预测（无对照人群）；诊断级/管理级决策（样本小、文本标签未人工复核）；
- 把概率当绝对风险使用（未稳定校准）。
